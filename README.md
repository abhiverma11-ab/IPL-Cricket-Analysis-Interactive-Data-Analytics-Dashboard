# IPL Cricket Analysis — Streamlit App

One file, one command, a full interactive dashboard.

## How to run it

**Step 1.** Open a terminal and go into this folder:
```bash
cd ipl_streamlit_app
```

**Step 2.** Install what it needs (only the first time):
```bash
pip install -r requirements.txt
```

**Step 3.** Start it:
```bash
streamlit run app.py
```

Your browser will open automatically to `http://localhost:8501` with the dashboard
already running — nothing else to click.

**To stop it:** go back to the terminal and press `Ctrl + C`.

## What you'll see

The page has 4 sections, top to bottom:
1. **Best Batsmen** — bar chart + scatter plot + full stats table
2. **Best Bowlers** — same, for bowling stats
3. **Winning Teams** — total wins and win % per team
4. **Toss Impact** — whether winning the coin toss actually helps win the match

On the **left sidebar** you can change settings (how many players to show, what
stat to rank by, minimum innings/overs to qualify) — the whole page updates
instantly, no button needed. That's one of Streamlit's main advantages over a
typical web app: every widget automatically re-runs the analysis.

## How to explain this project (e.g. to a class, interviewer, or teammate)

If you need to walk someone through it, here's a simple narrative, matching the
order things appear in `app.py`:

1. **"It loads three CSVs"** — one with match results, one with each player's
   batting performance per match, one with bowling performance per match.
   (`load_data()` function, cached so it's fast.)

2. **"The sidebar controls are just variables"** — every slider/dropdown in the
   sidebar becomes a Python variable (e.g. `top_n_bat`, `bat_rank_by`) that
   feeds directly into the pandas calculations below it. That's the entire
   trick behind Streamlit's interactivity — no callbacks or event handlers to
   write by hand.

3. **"Each section does the same 3 things"** — groups the data by player/team
   (`groupby`), computes a stat (runs, average, strike rate, wickets, economy,
   win %), then shows it 3 ways: a Matplotlib chart, a Plotly chart, and a raw
   table. Showing both chart libraries side by side is a deliberate choice —
   Matplotlib for a static, presentation-ready image; Plotly for an
   interactive one your audience can hover and zoom into.

4. **"Toss impact is the interesting one"** — it checks, for every match,
   whether the team that won the coin toss also won the match. Overall it's
   just over half the time, but it's more revealing split by decision
   (bat first vs. field first) and by season — that's the point of the two
   toss charts.

## About the data
This uses a **synthetic but realistic** sample dataset (10 teams, 2018–2024
seasons, ~315 matches) generated by `data/generate_data.py`, since no live
dataset was available to pull in. To use real data instead, replace the three
CSVs in `data/` with your own (same column names: see below) and restart the app.

- `matches.csv`: match_id, season, venue, team1, team2, toss_winner, toss_decision, winner
- `batting_innings.csv`: match_id, season, team, player, runs, balls, fours, sixes, out
- `bowling_innings.csv`: match_id, season, team, player, overs, runs_conceded, wickets
